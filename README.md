## 🌟 Flagship Project: RazorShield AI

> **[RazorShield AI — Real-Time Risk Engine & Autonomous Dispute Representment](https://github.com/Suryanshsaraf/razorpaytrack02)**  
> *Built for Razorpay AI Buildathon 2026 — Track 02 (AI Risk Manager)*  
> [![Live Demo](https://img.shields.io/badge/Live_Demo-Console-00D924?style=flat-square&logo=google-chrome&logoColor=white)](https://suryanshsaraf.github.io/razorpaytrack02/)
> [![Pitch Video](https://img.shields.io/badge/Pitch_Video-3:54_Demo-FF0000?style=flat-square&logo=youtube&logoColor=white)](https://youtu.be/GDoga27Ewnk)
> [![Docker](https://img.shields.io/badge/Docker-Ready-2496ED.style=flat-square&logo=docker)](https://github.com/Suryanshsaraf/razorpaytrack02/blob/main/docker-compose.yml)

A high-throughput, multi-modal risk mitigation system engineered for synchronous payment rails:
* ⚡ **Sub-2ms Decision Latency:** Quantized LightGBM + true binary Protobuf ONNX Runtime inference ($1.40\text{ms}$ single-sample) satisfying strict gateway checkout SLAs.
* 🛡️ **Visa Compelling Evidence 3.0 (CE 3.0) Agent:** Automated dispute dossier compiler correlating 3DS tokens, prior settled orders, and carrier GPS delivery telemetry (96% dispute win probability).
* 🕸️ **NetworkX Sybil Ring Sentinel:** Heterogeneous entity bipartite graph isolating coordinated card testing botnets and mutated Indian COD address rings.
* 📊 **Cost-Utility Objective Function:** Calibrated threshold tuning slashing False Positive Rate from $2.04\% \to 0.21\%$ and saving ₹15.5M+ in held-out merchant GMV.
